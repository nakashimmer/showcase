1.WebFontとは？

WebFont（ウェブフォント）は、Webページからフォントを読み込み、 利用者のパソコンやスマートフォンに同じフォントがインストールされていなくても、 指定したフォントで文字を表示できる仕組みです。

Google Fontsでは、HTMLの <link> でCSS APIを読み込み、CSSの font-family で利用するフォントを指定できます。

なお、指定したフォントが利用できない場合に備えて、 sans-serif などのフォールバックフォントも指定するのが基本です。

基本的な使い方

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Zen+Maru+Gothic&display=swap"> 

<style>
.sample {
  font-family: 
    "Zen Maru Gothic", 
    sans-serif; 
}
</style>
